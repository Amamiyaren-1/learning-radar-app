# Contributing

Use English commit titles and bodies: `type(scope): short English summary`. Aim for roughly 50–72 characters when useful, and explain rationale plus meaningful verification in the body. This is a project convention, not a Git limit. Keep communication with the owner Chinese.

Write developer documentation, comments, and docstrings in English. Preserve Chinese product strings, report/prompt templates, and synthetic test inputs/expectations. Preserve original third-party notices. Use a confirmed public author identity, preferably a GitHub noreply address; do not change export attribution or fabricate commit chronology.

Run the relevant offline checks in DEVELOPER-GUIDE.md. Use isolated fixtures and guard external connections. Do not call real models, collect GitHub projects, send mail, deploy, or publish without authorization. Keep native forms, authentication, budgets, quality gates, report states, and stable identity behavior intact.

Never commit private data or paid fonts. Use visibly synthetic screenshots. Public synchronization preserves English docs/licenses and public assets; see SOURCE-SYNC.md. The original-code license is pending approval, so review LICENSE before redistributing.
